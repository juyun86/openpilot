# 高架／高速变道闭环修复（2026-09-22，本地）

当前交付目标为高架与高速，城市路口转弯不作为本阶段交付条件。本轮修复本地变道协调器已复现的取消锁恢复和误计完成问题，未部署车机，不代表高速 NOA 已整体验收。

## 行为变化

- 已取消的动作不再因 inactive、event=0、无效会话或仅 routeRevision 改变而解除锁止。有效的新 maneuver 或新 session 才可重新准入；同方向或反方向不改变该事件的锁止。
- 相对靠边动作结束模型周期并稳定 500 ms 后，输出 `laneChangeCompletionUnconfirmed`，不增加成功次数、不自动请求下一道。局部车道索引即使变化，也不能作为独立的跨线证明。等待周期结束确认时撤销 ready，观测短暂失效也不能恢复 ready。
- 现有绝对索引路径保留稳定目标索引检查；当前 OEM 相对靠边路径不因此获得完成证明。现有配置次数上限不代表连续变道已经开放。
- 效率变道候选消费者识别完成未确认，终止当前请求，并锁止本导航会话中的后续效率变道，避免通过新的合成 event ID 绕过限制。有效的新导航会话可解除；消息中断及 routeRevision 改变不能解除。正常导航选道仍由其自身事件规则处理。
- 锁止为进程内状态，未实现跨进程重启持久化。道路类型准入、感知门禁、跟车、模型轨迹、方向盘控制及限幅未在本轮改写。

## 验证
